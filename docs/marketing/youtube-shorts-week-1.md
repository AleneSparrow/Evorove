# Evorove YouTube Shorts — week 1

Five generated Shorts. English only. No face. No fake product UI. No price, trial, or conversion claim.

Generate the torus loops **once**. Reuse them all week. Swap posters and voiceover per episode.

## Production defaults

| Item | Setting |
| --- | --- |
| Format | YouTube Shorts, 1080×1920, 30–40s |
| Voice | ElevenLabs, one US English female, calm documentary — not ads. Lock the voice ID. Stability ~0.60, similarity ~0.75, style ~0.15, speed 1.0 |
| Canvas | Cream `#F7F1E4`. Type already lives on the posters; do not overlay a second headline |
| Bed | Torus loop at 25–35% opacity behind the poster, or as 3s open / 3s close |
| Captions | Burned-in, Inter, ink `#0B0B0D`, first line = hook. No emoji |
| YouTube | Toggle **Altered or synthetic content**. No `$199`, no trial, no site card this week |
| CTA | Spoken: “Building in public.” End card: existing story or poster, not a new generate |

**Forbidden in VO and on-screen:** chatbot, intake assistant, CRM, cold lead, conversion %, “for lawyers.”

## Generate once — torus loops

Source stills (do not prompt a new torus from scratch):

- 9:16: `docs/brand/social/evorove-still-torus-story.png`
- 16:9 crop if the model refuses vertical: `docs/brand/social/evorove-still-torus-wide.png`, then crop center-top in CapCut

Export three clips, 5 seconds, no text, no people, loopable.

### Loop A — open / close (all five Shorts)

Kling / Veo, image-to-video:

```
Image-to-video. Keep this exact glossy coral torus and thin lime orbit on a cream studio floor. Slow orbital rotation, 5 seconds, seamless loop. Soft studio light from upper left. No new objects, no camera fly-through, no text, no hands, no screens, no particles beyond what is already in the still. Product-still motion only.
```

Negative:

```
text, watermark, person, face, phone, laptop, dashboard, UI, extra geometry, color shift, morphing, cartoon
```

### Loop B — hold under posters

```
Image-to-video. Same still. Almost static. Barely perceptible rotation of the coral torus, lime ring catching light. 5 seconds, loop. Cream background unchanged. No text.
```

### Loop C — cut between posters (optional)

```
Image-to-video. Same still. Slightly faster lime-ring travel around the torus, one orbit in 5 seconds. No zoom past 5%. No text.
```

If the model invents a second ring, a wheel, or a screen — discard and rerun. The mark is a torus, not a five-spoke wheel.

---

## CapCut recipe (every episode)

1. New project 9:16.
2. Full-bleed Loop A, 0:00–0:03.
3. Poster (listed below) centered, ~92% width, cream bars if the file is 16:9.
4. Loop B under the poster for the body.
5. Loop A again, 3s, end.
6. Drop ElevenLabs take. Auto captions. Delete any caption that duplicates the poster headline while that poster is on screen.
7. Export 1080×1920, H.264.

Story files are already 9:16 — use them full-bleed, no bars.
